# 📡 Falcon Telecom Analytics Dashboard

An end-to-end **Business Intelligence project** built to analyze the performance of a simulated telecom operator using **Python, Excel, Power Query, and Power BI**.

The dashboard provides executives with insights into customers, subscriptions, revenue, billing, network performance, and branch/employee productivity to support **data-driven decision-making**.

---

# 📌 Project Overview

This project simulates a real-world telecom environment by generating realistic telecom data using Python (Faker), storing and managing it in Excel, cleaning and transforming it using Power Query, and building an interactive Power BI dashboard.

The dashboard answers key business questions such as:

* How is the company performing overall?
* Who are the customers, and where are they concentrated?
* Who is churning, and why?
* How is revenue collected, and where are payments delayed?
* Is the network holding up, and where are the weak spots?
* Which branches and employees are driving results?
* How does company performance change over time?

---

# 🧹 Data Preparation

The raw telecom data was generated with **intentional data quality issues** to simulate a realistic dataset, then reviewed and cleaned before analysis.

The data preparation process included:

* Handling missing values (nulls in salaries, satisfaction scores, payment methods)
* Removing duplicate records
* Standardizing inconsistent text casing (e.g. job roles)
* Trimming inconsistent spacing in names
* Detecting and removing statistical outliers (e.g. abnormal data usage values)
* Reconciling payments against invoices to confirm data consistency
* Validating dates and numerical fields
* Preparing the data for Power BI modeling
